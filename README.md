# 💻 Personal Portfolio Website

A modern and responsive **personal portfolio website** built using **HTML, CSS, and JavaScript**.  
It showcases skills, education, projects, certifications, resume, and contact information with a clean and interactive design.

---

## 🚀 Features

- 👋 Modern and responsive hero section
- ⌨️ Typing animation
- 👨‍💻 About Me section
- 🎓 Education section
- 🛠️ Technical skills showcase
- 📂 Projects section
- 📜 Certifications section
- 📄 Resume download
- 📧 Contact form
- 🔗 GitHub and LinkedIn integration
- 📱 Responsive design
- ✨ Animations and glowing effects

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome
- EmailJS
- Vercel
